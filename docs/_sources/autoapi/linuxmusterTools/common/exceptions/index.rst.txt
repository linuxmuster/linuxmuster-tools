linuxmusterTools.common.exceptions
==================================

.. py:module:: linuxmusterTools.common.exceptions




Module Contents
---------------

.. py:exception:: SchoolError

   Bases: :py:obj:`Exception`


   Raised when an operation is given an invalid or unresolvable school scope,
   e.g. 'global' where a single, concrete school is required.


.. py:exception:: LdapNotProvisionedError

   Bases: :py:obj:`Exception`


   Raised when LDAP/Samba credentials are requested before linuxmuster-setup
   has provisioned the domain (e.g. fresh install, setup wizard not completed yet).


.. py:exception:: SchoolclassExistsError

   Bases: :py:obj:`Exception`


   Raised when the subgroups of a schoolclass are requested to be deleted
   while the schoolclass itself still exists in LDAP.


.. py:exception:: UnknownTemplateTypeError

   Bases: :py:obj:`ValueError`


   Raised when a print template has a type with no known output name
   (none of schoolclass, passwords, passwordslarge).
