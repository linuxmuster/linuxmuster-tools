linuxmusterTools.common.parsers.sophomorix_log.parse_kill_log(all=False, epoch=None, today=False, lastweek=False)[source]

Parse the kill log of sophomorix to return a dict with all informations. Informations available in the log: - timestamp - utc datetime - school - user’s cn - user’s lastname - user’s firstname - sophomorixAdminclass - sophomorixRole

Parameters:

  • all (bool) – return all entries

  • epoch (basestring) – search the given epoch/timestamp in the log

  • today (bool) – filter only today’s results

  • lastweek (bool) – filter only last week’s results

linuxmusterTools.common.parsers.sophomorix_log.parse_update_log(all=False, epoch=None, today=False, lastweek=False, list_changes=True)[source]

Parse the update log of sophomorix to return a dict with all informations. Informations available in the log: - first log line:

  • timestamp

  • utc datetime

  • school

  • user’s cn

  • group change (e.g. teachers->attic)

  • role change (e.g. teacher->student)

  • second log line:

    • timestamp

    • utc datetime

    • school

    • user’s cn

    • list of LDAP attributes changes (separator “=”)

Parameters:

  • all (bool) – return all entries

  • epoch (basestring) – search the given epoch/timestamp in the log

  • today (bool) – filter only today’s results

  • lastweek (bool) – filter only last week’s results

  • list_changes (bool) – list the LDAP attributes changed

Returns:

entries

Return type:

dict
