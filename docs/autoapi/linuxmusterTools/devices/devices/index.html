check_conf()[source]

Validate the inventory of this school, reporting everything found instead of stopping at the first problem.

Only this school is read, so a host name, a mac address or an ip address shared with another school can not be seen here: use check_all_schools() for that.

Returns:

valid, counts, findings and report (see InventoryValidator.validate)

Return type:

dict

linuxmusterTools.devices.devices.list_schools(root=None)[source]

List the schools holding a devices.csv on this server.

This reads the filesystem rather than ldap on purpose: what is validated here are the files, and a caller already holding the authoritative list of provisioned schools passes it to check_all_schools() instead.

Parameters:

root (string or Path) – Directory holding one subdirectory per school

Returns:

Sorted school names

Return type:

list

linuxmusterTools.devices.devices.check_all_schools(schools=None)[source]

Validate the inventories of every school at once, which is the only way to see a host name or a mac address used twice in two different schools.

Parameters:

schools (list) – Schools to validate, discovered on disk if not given

Returns:

valid, counts, findings and report (see InventoryValidator.validate)

Return type:

dict
