linuxmusterTools.linbo.linbo_sync

LINBO remote commands — build, run and track linbo-remote sessions.

linbo-remote sends actions (format/sync/start/halt/…) to hosts over ssh. Each run happens in a detached tmux session named “<hostname>_linbo-remote”, and logs to LINBO’s log directory: one <hostname>_linbo-remote_<YYYYmmddHHMMSS>.log per run since linuxmuster-linbo7 7.4.18, a single <hostname>.linbo-remote overwritten by each run before (see LinboBootLogs.latest_remote_log()).

Returns:

Status dict {‘status’: 0, ‘msg’: <command output>} on success, or {‘status’: 1, ‘msg’: <error>} if some hosts were offline.

Return type:

dict

Raises:

LinboRemoteParameterError – if linbo-remote itself rejected the command line (e.g. unknown group/room, no valid host in a -i list, missing command) — it validates clients/group/room and exits non-zero before running anything in that case.

linuxmusterTools.linbo.linbo_sync.attach_command(hostname: str) → str[source]

Build the tmux attach command for a host’s running linbo-remote session.

Not meant to be run through a web request: tmux attach needs an interactive terminal (a pty), which a stateless HTTP call can’t provide. Exposed so a future terminal-in-browser feature (websocket + pty) has the exact session name to attach to.

Parameters:

hostname (str) – Hostname whose session to attach to

Returns:

Shell command string, e.g. “tmux attach -t pc001_linbo-remote”

Return type:

str
