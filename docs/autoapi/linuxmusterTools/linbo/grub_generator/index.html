linuxmusterTools.linbo.grub_generator

LINBO GRUB Config Generator — generate GRUB boot configs from data objects.

Pure template-based generation: - Main grub.cfg (PXE boot with MAC→group mapping) - Per-config {group}.cfg (OS menu entries) - Hostcfg symlinks (hostname.cfg + 01-{mac}.cfg)

Device path translation, OS type detection, template variable substitution.
