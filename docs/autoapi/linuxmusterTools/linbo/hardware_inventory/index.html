linuxmusterTools.linbo.hardware_inventory

Read DMI information uploaded by LINBO clients.

LINBO stores one compressed <hostname>_hwinfo.gz file per client in /var/log/linuxmuster/linbo. The inventory manager combines these files with the school-scoped client records already provided by Devices. It is read-only and deliberately independent from driver profiles and hooks.
