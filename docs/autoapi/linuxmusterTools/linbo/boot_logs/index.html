linuxmusterTools.linbo.boot_logs

LINBO Boot Logs — read client boot logs from /var/log/linuxmuster/linbo/.

Provides safe file listing, reading, and deletion with path traversal protection.

list_logs() → list[dict][source]

List all log files with metadata.

Returns:

List of {filename, hostname, size, modifiedAt} dicts, sorted newest first. hostname is None for a file whose name says nothing about a host; it is a name no inventory matches for the ones that belong to no machine anyway, like a multicast log (bionic.cloop_mcast.log) or a client that could not identify itself (UNKNOWN_linbo.log).

latest_remote_log(hostname: str) → str | None[source]

Name of the log of a host’s last linbo-remote run.

The newest <hostname>_linbo-remote_<YYYYmmddHHMMSS>.log, ordered on the timestamp of its name, or the <hostname>.linbo-remote written by linuxmuster-linbo7 before 7.4.18 if the host has no other.

Args:

hostname: Name of the host

Returns:

File name to pass to read_log(), or None if the host has no linbo-remote log

Raises:

ValueError: If hostname is not a valid host name
