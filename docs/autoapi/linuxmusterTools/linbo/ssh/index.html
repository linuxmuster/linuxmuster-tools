linuxmusterTools.linbo.ssh

LINBO SSH Service — execute commands on LINBO clients via SSH.

Uses the system ssh client. Key loading is lazy: the private key is loaded on first use, not at module import time.

Default connection: root@host:2222 with RSA key from /etc/linuxmuster/linbo/ssh_host_rsa_key_client
