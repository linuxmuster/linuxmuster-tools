get_all_members()[source]

Set a members and admins list by recursively scanning all groups and their members which are members or admins of this project.

This is not called as post init because of nested projects. So it’s necessary to call this method afterwards:

p = lr.get(‘/projects/p_test’, dict=False) p.get_all_members()
