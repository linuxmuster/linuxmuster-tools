class linuxmusterTools.lmnconfig.sophomorix.ComputerRoles[source]

What sophomorix.ini says about computer roles: the ones getting a machine account in the AD, the ones getting a DNS node only, and the one an empty role field means.

Read by SophomorixIni into its computer_roles attribute, or built by hand to pin what a caller reads - a test, or a check run against an inventory coming from somewhere else.
